# IDSpace Dataset

## Dataset Summary

IDSpace contains a large-scale synthetic dataset designed for the evaluation and benchmarking of digital identity verification and document fraud detection systems. The dataset was generated using the IDSpace framework, a model-guided synthetic document generation methodology that aligns generated documents with a target domain using only a small number of real samples.

Unlike existing synthetic identity document datasets that focus primarily on visual realism, IDSpace is designed to preserve **prediction consistency** between real and synthetic documents, enabling more reliable evaluation of fraud detection systems under severe data scarcity.

The dataset contains **359,240 synthetic identity document images** spanning:

* 10 European identity document types
* Template-generated documents
* Scanner-captured document simulations
* Mobile-captured document simulations
* Genuine documents
* Multiple document fraud scenarios

All images and metadata are synthetically generated and contain **no real personal information**.

This dataset accompanies the paper and source code:

> *IDSpace: A Novel Document Generator for Reliable Evaluation of Digital Identity Verification Systems*
> 
> https://github.com/asu-cactus/IDSpace

## Key Features

* 359,240 synthetic document images
* 10 European identity document types
* Three modalities:

  * Template documents
  * Scanned documents
  * Mobile-captured documents
* Two realistic fraud types:

  * Inpaint-and-Rewrite
  * Crop-and-Replace
* Rich metadata annotations
* Country-specific document templates

## Dataset Composition

The dataset contains:

| Component          | Description                                                                                           |
| ------------------ | ----------------------------------------------------------------------------------------------------- |
| Template Documents | Synthetic identity documents generated directly from document templates                               |
| Scanned Documents  | Simulated scanner captures with realistic noise, shadows, rotation, and scanning artifacts            |
| Mobile Documents   | Simulated mobile captures generated by blending identity documents into real mobile-scene backgrounds |
| Fraud Documents    | Manipulated documents representing common identity fraud scenarios                                    |
| Metadata           | JSON annotations describing document fields and generation parameters                                 |

## Dataset Structure

### Template Archives

Each `LOC_template.tar.gz` archive contains:

```text
LOC_template/
├── positive/
├── fraud_inpaint_and_rewrite/
├── fraud_crop_and_replace/
└── meta/
    ├── LOC_original_annotation.json
    ├── LOC_inpaint_and_rewrite.json
    └── LOC_crop_and_replace.json
```

#### positive

Contains non-fraudulent synthetic identity documents.

#### fraud_inpaint_and_rewrite

Contains forged documents generated using the inpaint-and-rewrite fraud pattern.

#### fraud_crop_and_replace

Contains forged documents generated using the crop-and-replace fraud pattern.

#### meta

Contains image-level metadata and annotations corresponding to each document category.

---

### Scan Archives

Each `LOC_scan.tar.gz` archive contains scanned versions of the corresponding template documents.

The scan generation pipeline simulates:

* Scanner backgrounds
* Rotation
* Position offsets
* Brightness variation
* Contrast variation
* Blur
* Noise
* ...

These documents emulate real-world scanned identity documents used by verification systems.

---

### Mobile Images

`Mobile_images.tar` contains 500 mobile-captured document images.

For each of the ten countries:

* 50 mobile images were generated
* A synthetic identity document was blended into a real mobile-scene background
* Backgrounds were sampled from MIDV

These images simulate realistic user-submitted identity document photos.

---

### Models

`models.tar.gz` contains pretrained models used during the IDSpace generation process.

These models are provided for reproducibility and research purposes.

## Generation Methodology

IDSpace uses a model-guided generation framework that optimizes document generation parameters using Bayesian optimization and prediction consistency objectives.

The generation process:

1. User specifies document metadata.
2. Control parameters are automatically tuned.
3. Synthetic documents are generated.
4. Documents are transformed into scanned and mobile formats.

The framework supports:

* Demographic customization
* Fraud pattern customization
* Scanner simulation
* Mobile capture simulation
* Few-shot domain adaptation

Additional methodological details are available in the accompanying paper.

## Ethical Considerations

All identities, portrait photographs, and metadata used in IDSpace are synthetically generated.

The dataset does not contain real personal information and was designed to support privacy-preserving evaluation of identity verification systems.

To mitigate misuse, generated documents do not contain functionally valid identity credentials, such as operational machine-readable zones or scannable barcodes.
